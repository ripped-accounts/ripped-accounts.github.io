1

Windows Security

Disable real-time protection and core isolation
1
Open Windows Security

Press Win + S, type Windows Security, and open it.

2
Virus & Threat Protection → Settings

Click Virus & Threat Protection → scroll down → click Manage Settings. Turn OFF these in order:

  • Tamper Protection (do this one first)
  • Real-Time Protection
3
Device Security → Core Isolation

Go back home → Device Security → Core Isolation Details → turn off everything shown.

🔧 Troubleshoot — Memory Integrity greyed out?

Open Command Prompt as Administrator and run these two commands one at a time:

CMD — Command 1
reg add HKLM\SYSTEM\CurrentControlSet\Control\CI\Config /v VulnerableDriverBlocklistEnable /t REG_DWORD /d 0 /f
CMD — Command 2
reg add "HKLM\SYSTEM\CurrentControlSet\Control\DeviceGuard\Scenarios\HypervisorEnforcedCodeIntegrity" /v "Enabled" /t REG_DWORD /d 0 /f
⏸️
Don't restart yet
Run the commands and continue — you'll restart after D-Control in Step 2.
2

Download & Run D-Control

Keeps Defender off permanently across reboots
1
Download D-Control

👉 https://gofile.io/d/LHMqbjIC

Why We Do This

An honest breakdown — no malware, we promise
🔒
This software does not install any malware.
Here is exactly why each step is required, in plain language.
🛡️

Disabling Windows Defender

Our loader uses a low-level kernel driver that Defender flags the same way it flags any unsigned system driver. We need it off so the software isn't blocked before it even starts.

🔧

D-Control (Recommended)

Without D-Control, Defender re-enables itself on every restart. D-Control keeps it off so you don't have to redo Step 1 on exam day.

🧠

Core Isolation / HVCI

Memory Integrity (HVCI) blocks unsigned kernel drivers from loading. Our stealth driver needs this off to operate invisibly. It never touches your personal files.

✅

After Exam — Restore Your Computer

Back to 100% normal in under 5 minutes
✅
Do this right after your exam ends
You're just re-enabling what you turned off. Your PC will be completely back to normal.
1
Open D-Control → “Enable Windows Defender”

If it says service couldn't start, restart your computer and try again — works after reboot.

2
Re-enable the driver blocklist and HVCI

Open Command Prompt as Administrator and run both commands:

CMD — Restore 1
reg add "HKLM\SYSTEM\CurrentControlSet\Control\CI\Config" /v "VulnerableDriverBlocklistEnable" /t REG_DWORD /d 1 /f
CMD — Restore 2
reg add "HKLM\SYSTEM\CurrentControlSet\Control\DeviceGuard\Scenarios\HypervisorEnforcedCodeIntegrity" /v "Enabled" /t REG_DWORD /d 1 /f
3
Re-enable Virus & Threat Protection

Windows Security → Virus & Threat Protection → Manage Settings → turn everything back ON.

4
Re-enable Core Isolation

Windows Security → Device Security → Core Isolation Details → turn everything back ON.

5
Restart your computer

One final restart and your system is fully restored. You're done. 🎉
